# Creating Store Assets Table

> Creating Store Assets table. It will contain following columns
> 
- laptop_serial_number
- laptop_model
- status
- end_of_life

> Rules to follow while creating table
> 
1. here in this table in case of serial number in assets it will be some keyword having there product_name  which will be further cleaned in next steps
2. status will be either stock , issued and dispose
3. end_of_life refers to product out of service it will be either yes, no, n/a or null 
4. total number of stock will be greater than issued accessories
