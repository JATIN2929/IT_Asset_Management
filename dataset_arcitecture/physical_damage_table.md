# Creating Physical Damage Table

> Creating Physical Damage table. It will contain following columns
> 
- date
- staff_id
- staff_name
- laptop_model
- laptop_serial_number
- Damage_detail
- Cost_code

> Rules to follow while creating table
> 
- this is only for laptops not for other accessories
- damage detail refers to display damage,hinge damage, water spillage , mother board
- cost_code will come from user profile
