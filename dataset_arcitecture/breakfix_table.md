# Creating Breakfix Table

> Creating Break Fix table. It will contain following columns
> 
- date
- staff_id
- staff_name
- reason
- old_asset_model
- old_asset_serial_number
- replaced_asset_model
- replaced_asset_serial_number
- hostname
- issue
- remarks

> Rules to follow while creating table
> 
- Reason will contain values breakfix,transfer and new joiner
- issue will be hardware or software
- date is the date on which asset change took place
