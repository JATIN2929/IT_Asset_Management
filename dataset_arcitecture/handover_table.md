# Creating Handover Table

> Creating Handover table. It will contain following columns
> 
- date
- staff_id
- staff_name
- laptop_model
- laptop_serial_number
- other_accessories
- remarks

> Rules to follow while creating table
> 
- remarks is either transfer , dual asset , temporary asset handover and last working day
